# Tracy — Landing Pages de Campanha

Este repositório contém as landing pages de campanha do Tracy, separadas por ângulo/dor atacada.

## LPs ativas

- **`tracy-lp-trafego/`** — "Tráfego é difícil é o que te contaram. Não o que é."
  Foco: medo/dificuldade de fazer tráfego pago.

## Como adicionar uma nova LP

1. Duplique uma pasta existente (ex: `tracy-lp-trafego`) e renomeie
2. Ajuste o copy no `index.html`
3. O CSS e JS podem ficar iguais (consistência visual entre LPs)
4. Abra uma PR para revisão

## Deploy

Deploy automático via Vercel. Cada PR gera um preview URL.
